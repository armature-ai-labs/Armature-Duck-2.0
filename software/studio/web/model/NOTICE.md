# Model Provenance

`model.json` + `meshes.bin` are generated by `../build_model.py` from
[apirrone/microduck_rl](https://github.com/apirrone/microduck_rl)
`src/mjlab_microduck/robot/microduck/robot_allcollisions.xml` and `assets/*.stl` (2026-09-17 snapshot),
licensed under Apache License 2.0. Meshes come from Pollen Robotics official Microduck CAD,
keeping external shells only with int16 vertex quantization.

`stills/*.webp` are rendered action thumbnails produced from the same 3D model.
